配置与安全说明
  1. Levis「接口管理」新增 Virtualis 接口，填写主控 HTTP(S) 地址与 API 密钥。生产环境使用 HTTPS，密钥具备所需 images:read、instances:read / instances:write 权限。
  2. 先在 Virtualis 节点配置可用独立 IP 池与上联接口，并配置安全组及规则。节点驱动与商品驱动必须一致。
  3. 默认输出可直接作为管理员商品 API 的 provision_config，或使用 Levis 商品编辑器保存同名字段。生成 JSON 不等于保存；粘到商品描述不会生效。商品预设的镜像由买家选择，单次 RPC 模式才使用本页镜像 ID。
  4. 选 IP 池应留空手工 IPv4；显式地址、网关、DNS / 接口优先于上游默认值。VPC 使用 network_mode=vpc 与对应 vpc_id。
恢复、改配与终止语义
  • 快照 / 备份支持列表、创建、恢复与删除。备份经认证流式下载，每块 64 KiB、上限 64 GiB；不会返回含密钥的下载链接。
  • 改配使用 typed resources，保留原网络和架构；需关机，不支持磁盘缩小。已应用的相同规格重试不会再次改配。
  • 终止服务永久清理上游实例（/purge），不同于回收站软删除。迁移、批量、回收站和全局网络写操作必须由 Levis 管理员入口授权。
  • 用户服务功能界面由 Levis 提供。本页不直接执行恢复或迁移；真实 Incus / libvirt 行为需部署环境联调。
