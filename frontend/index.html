Virtualis 对接插件

让本站商品可以直接在上游 Virtualis 弹性云主机系统上开通（容器 / 虚拟机）。

  1. 在 接口管理 新增接口：模块选择「Virtualis 对接」， 填写上游 Virtualis 地址 与 API 密钥，并点击测试确认连通。
  2. 在 商品管理 新建商品：接口选择刚添加的接口， 驱动选 Incus（容器）或 QEMU（虚拟机）， 配置类型选「弹性云」（设定各项规格的最小/最大值，用户购买时自选） 或「管理员固定配置」。
  3. 用户购买时选择规格与系统镜像（Incus 只能装 Incus 镜像，QEMU 只能装 QEMU 镜像）， 支付后自动在上游开通实例；已购服务支持开机 / 关机 / 重启。

上游需开放 /api/v1 机器 API（API Key 鉴权）， 密钥在 Virtualis 后台「安全 → API 密钥」生成。
